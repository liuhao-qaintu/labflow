# 使用指南

## 资源查询与预约

登录后可浏览实验室与设备，查看开放时间、位置和使用状态。选择资源、日期和时段后提交预约，申请进入待审核状态；管理员审核通过后方可使用。用户可在预约记录中查看状态，并取消本人待审核的申请。

## 智能助手

助手可以查询实验室与设备、检索预约和安全规则，并辅助提交预约。描述需求时可包含资源名称、日期和起止时间；信息不足时补充相应内容。

提交前核对确认卡中的资源、日期和时段。选择拒绝时不执行写入；确认后创建待审核预约。提交结果与审批状态可在预约记录中核对。

## 管理员操作

资源管理员维护实验室和设备、处理预约审批，并在用户管理中处理分配给自己的找回密码申请。维护接口需要额外的服务端白名单授权。

## 找回密码

1. 在登录页选择“忘记密码”，填写必填用户名；姓名、邮箱、手机号和证明说明可选。
2. 提交后保存43位申请凭据。凭据有效30天，在“凭据查询与跟进”中可查看状态、管理员回复并补充材料；申请编号不能代替凭据。
3. 管理员根据材料独立核验，可要求补充、拒绝申请或核验后重置。
4. 核验重置后，通过原凭据查看本次仍有效的初始密码，登录后立即修改，再使用新密码登录。

凭据丢失后需重新申请。凭据可以访问申请材料和获批后的登录指引，应妥善保管。请勿在申请说明中填写原密码或验证码。
