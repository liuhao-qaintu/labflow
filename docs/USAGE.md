# 使用指南

labFLow 支持通过资源页面提交预约，也可以先向智能助手询问资源和制度，再核对预约信息。两种方式都通过同一套业务服务创建申请，提交后进入管理员审核。

## 选择使用入口

| 当前需求 | 推荐入口 | 核对重点 |
| --- | --- | --- |
| 已经明确实验室或设备 | 资源列表 | 资源、日期、起止时间 |
| 还需要了解资源与规则 | 智能助手 | 查询结果、制度说明和确认信息 |
| 查看后续结果 | 我的预约 | 是否已提交、当前审核状态 |
| 审核或维护资源 | 管理员页面 | 申请信息与对应业务权限 |

## 通过资源页面预约

1. 登录后浏览实验室与设备，查看位置、开放时间和使用状态。
2. 选择资源，填写日期、开始与结束时间，按需要补充备注。
3. 提交成功后，前往“我的预约”核对待审核记录。
4. 管理员审核后查看更新状态，并按实际制度安排使用。

普通用户可以查看本人预约，并取消本人仍处于待审核状态的申请。取消与审核均由后端校验账号和申请状态。

## 使用智能助手

描述需求时，可同时说明资源名称、日期、起止时间和需要了解的制度，例如：

> 明天 14:00 到 16:00 想使用计算机实验室的 GPU 工作站，需要哪些预约信息？

助手可调用日期、实验室、设备和知识库查询工具。信息不足时继续补充，资源查询结果与预约写入结果分别核对。

### 核对确认卡

当助手准备创建预约时，图执行暂停并返回待确认信息。确认前重点查看：

- 实验室和设备是否对应本次需求。
- 日期是否正确，尤其是“今天”“明天”等相对日期。
- 起止时间、备注及资源选择是否完整。

确认后才执行本次预约工具；拒绝时该工具不写入。提交还需通过业务校验，成功后形成待审核记录。确认提交不等于管理员已经批准，最终结果以预约记录为准。

## 管理员协作

管理员维护实验室与设备，处理预约审核，并在用户管理中查看分配给自己的账号恢复申请。账号恢复的接收管理员由服务端指定。

维护功能额外检查服务端白名单，不因用户能够进入业务管理页面就自动开放。

## 账号恢复与处理跟进

```mermaid
graph LR
    A["提交核验表单"] --> B["保存申请凭据"]
    B --> C["查询进度与补充材料"]
    C --> D["管理员核验与处理"]
    D --> E["核验重置后领取初始密码"]
    E --> F["登录并强制改密"]
```

1. 在登录页选择“忘记密码”，填写必填用户名；姓名、邮箱、手机号和证明说明可选。
2. 提交后保存申请凭据，在“凭据查询与跟进”中查看状态、管理员回复并补充材料。
3. 管理员根据材料独立核验，可以要求补充、拒绝申请或核验后重置。用户名用于定位申请对象，不自动证明身份。
4. 核验重置后，通过原凭据查看本次仍有效的初始密码。登录后先修改密码，再用新密码登录。

申请凭据为 43 位，有效 30 天；申请编号不能代替凭据。凭据可以访问申请材料和获批后的登录指引，应妥善保管。丢失后需重新申请，表单中不要填写原密码或验证码。

## 核对处理结果

对话中断或返回错误时，先查看预约记录，确认是否已经成功提交。资源制度由管理员维护，助手的说明需结合实际制度和当前查询结果使用。

如需调整模型服务、知识库或恢复申请配置，查看[配置与维护](OPERATIONS.md)；维护和验证方式见[测试说明](TESTING.md)。
